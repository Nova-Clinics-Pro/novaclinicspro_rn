## Findings

- Seven current E8 `ACTIVE` trial rows exist. All belong to tenants retaining
  the historical `TRIAL` projection; none demonstrates the new
  `NOT_STARTED`-plus-active-E8-trial cohort.
- Two legacy subscription rows are in status `trial`; neither is active paid
  evidence under the B4 entitlement predicate.
- There are 44 completed setup-progress rows. Six tenants have readiness rows
  without active paid/E8 evidence (five legacy-trial records and the one
  insufficient-evidence record). This proves coexistence only; it does not
  prove readiness caused commercial activation. Current B4 code keeps readiness
  outside entitlement evaluation.
- No record has multiple active authoritative paid/trial facts and no active
  paid plus active E8 trial overlap was observed.

## Remediation assessment

No automatic remediation is authorized. The 17 legacy-trial records and one
insufficient-evidence record require manual owner/data-governance review. The
evidence does not support changing subscription projections, recreating trials,
or using readiness to infer entitlement.

## Reproducibility

Read-only queries selected: database time zone and Alembic revision; schema
presence and columns; aggregate distribution by tenant projection, subscription,
E8 trial, legacy session, and readiness state; and a tenant-level left join of
those five sources. The tenant-level query uses `md5(tenant_id::text)` for a
non-sensitive stable record reference, and its active predicates exactly mirror
`CommercialEntitlementService`.

```sql
WITH observed AS (SELECT now() AS ts), evidence AS (
  SELECT t.id, t.subscription_status,
    count(DISTINCT s.id) FILTER (
      WHERE s.status = 'active' AND s.current_period_end >= (SELECT ts::date FROM observed)
    ) AS active_paid_count,
    count(DISTINCT ct.id) FILTER (
      WHERE ct.state = 'ACTIVE' AND ct.expires_at > (SELECT ts FROM observed)
    ) AS active_trial_count,
    count(DISTINCT ct.id) AS e8_trial_count,
    count(DISTINCT ots.id) AS legacy_trial_session_count,
    count(DISTINCT osp.id) AS readiness_progress_count
  FROM public.org_tenants AS t
  LEFT JOIN public.org_subscriptions AS s ON s.tenant_id = t.id
  LEFT JOIN public.org_commercial_trials AS ct ON ct.tenant_id = t.id
  LEFT JOIN public.org_trial_sessions AS ots ON ots.tenant_id = t.id
  LEFT JOIN public.org_setup_progress AS osp ON osp.tenant_id = t.id
  GROUP BY t.id, t.subscription_status
)
SELECT substr(md5(id::text), 1, 12), subscription_status,
       active_paid_count, active_trial_count, e8_trial_count,
       legacy_trial_session_count, readiness_progress_count
FROM evidence;
```
