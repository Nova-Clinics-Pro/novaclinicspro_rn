## 3. CS-006 finding and reproduction

`ChoiceScreen` previously derived an application ID when an authenticated user had a continuation with `kind === 'approved_choice'`. Unlike the root resolver, it did not require a UUID application ID, a nonblank tenant name, or an `approved` registration status.

Before the production correction, the direct-entry regression command was:

```bash
yarn jest --runInBand --no-cache --watchman=false \
  tests/onboarding/ChoiceScreen.clinic-entry.test.tsx
```

It failed with **4 failures / 18 passes**. Invalid data enabled the query, including:

- `application_id: 'not-a-uuid'` → received `enabled: true`;
- missing or blank `tenant_name` → received `enabled: true`;
- `pending_review` with a valid-looking continuation → received `enabled: true`.

This directly reproduced B2.7-CS-006's security finding at the mounted screen boundary.

## 4. Canonical validator reuse

The complete FIX-03 validator already existed in:

`frontend/features/registration/presentation/registrationStatusRouting.ts`

It checks non-null object shape, excludes arrays, requires `kind: 'approved_choice'`, validates the UUID, and requires a nonblank tenant name. FIX-05 exports that existing pure function as `isApprovedChoiceContinuation`; it does not duplicate or weaken its rules.

## 5. Minimal production correction

Changed production paths:

- `frontend/features/registration/presentation/registrationStatusRouting.ts`
- `frontend/features/onboarding/presentation/pages/ChoiceScreen.tsx`

`ChoiceScreen` now derives an application ID only when all of the following hold:

1. an authenticated `currentUser.userId` exists;
2. the authoritative registration-status result is `approved`;
3. its continuation passes `isApprovedChoiceContinuation`.

Otherwise it passes `''` with `enabled: false` to `useApplicationDetailQuery`. Route parameters remain unused and cannot override the authenticated continuation. No direct Axios call, repository bypass, cache-key change, tenant authorization inference, or backend authorization replacement was introduced.
